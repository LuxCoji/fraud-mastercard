A transformer that reads a card's whole story — and catches the twist.

TREASURE is a decoder-only Transformer foundation model for payment transactions, reimplemented from Visa Research's arXiv:2511.19693. It scores every transaction in the context of the cardholder's full history, so it flags fraud that no single-row model can see — sleepers, behavioural drift, low-and-slow mule activity.

The Red Team writes the attacks the defender hasn't learned to detect yet. The Blue Team learns to detect them.

Under the hood

faithful to the paper, Section 3

How one transaction is scored

input
Input module — numericals log-scaled → linear; categoricals → embedding tables; fused through a GELU MLP.
sequence
Causal Transformer decoder — static vector placed first, no positional encoding; attends only to the past.
heads
Dual output — one head predicts the next transaction, one predicts current network signals incl. the abnormal flag.
loss
Four objectives — log-normal NLL, cross-entropy, InfoNCE with shared negatives for 50k+ merchants, all pivoted on the abnormal flag.

Reproduce it

three commands, one GPU 
# 1 · generate the synthetic attack ledger (Red Team)
python -m treasure.data_gen --n_cards 20000 --out data/txns.npz

# 2 · train TREASURE on the GPU (Blue Team)
python -m treasure.train --data data/txns.npz --epochs 20 --batch_size 128 --max_seq_len 256

# 3 · score a card and print its risk timeline
python -m treasure.demo  --ckpt checkpoints/treasure.pt --data data/txns.npz
